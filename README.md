# 🎮 VALOcus Discord Bot

VALORANTのカスタムマッチにおいて、参加者のランク・内部レート（Rating）を管理し、**実力が均等になるよう自動でチーム分け**を行うDiscord Botです。  
試合結果を記録することで内部レートが変動（勝者+1pt / 敗者-1pt）し、**次の試合のチーム分けが自動で生成**されます。

---

## 🚀 主な機能

- **ランク自動取得 & 手動設定** (Valorant API対応)
- **ワンクリック参加 / 辞退機能**
- **内部レートベースの勝敗追跡 & 自動チーム再編成**
- **参加者のランク分布確認コマンド**

---

## 📖 使い方ガイド

### 1. 初回準備（ランク登録）
メンバー各自で自分のランクを登録します。

* **自動登録（推奨）**  
  `!register 名前#TAG`  
  *(例: `!register Taro#JP1` / Valorant APIから最新ランクを取得)*
* **手動登録**  
  `!setrank ランク名`  
  *(例: `!setrank ダイヤ2` / `!setrank g3` / `!setrank イモ1`)*
* **登録情報の確認**  
  `!myrank`

---

### 2. カスタム募集の開始
進行役（ホスト）がコマンドを入力して募集パネルを出します。

1. チャット欄で `!custom` と入力
2. 送信された募集パネルで参加者を募集

---

### 3. 参加・辞退
* **参加する：** パネル下の **[参加する]** ボタンを押す
* **辞退する：** パネル下の **[辞退する]** ボタンを押す
* **内訳確認：** `!members` で現在の参加者のランク分布を確認

---

### 4. チーム分け実行
メンバーが集まったら、募集パネルの **[均等チーム分け実行]** ボタンを押します。  
現在の内部レートを基に **🔴 チームA** と **🔵 チームB** へ自動で振り分けられます。

---

### 5. 試合終了・勝敗記録（自動連続処理）
試合が終わったら、勝利したチームのボタンを押します。

1. **[🔴 チームA 勝利]** または **[🔵 チームB 勝利]** をクリック
2. **自動反映：** 勝者メンバー全員 `+1pt` / 敗者メンバー全員 `-1pt`
3. **次戦チーム分け：** レート変動後の「新しいチーム分け結果」が自動で下に表示されます

> 💡 **2試合目以降：**  
> 新しく出力されたチーム分け結果の下にある勝利ボタンをそのまま押していくだけで、連続して記録とチーム分けが行えます。

---

## 🛠 コマンド一覧

| コマンド | 説明 |
| :--- | :--- |
| `!custom` | カスタム募集パネルを表示します |
| `!members` | 現在参加中のメンバーのランク別内訳を表示します |
| `!register <RiotID#TAG>` | Riot IDを登録し、最新ランクを自動取得します |
| `!setrank <ランク>` | ランクを手動で設定・更新します |
| `!myrank` | 自分の登録情報（Riot ID・ランク・内部レート）を確認します |
| `!valocus` | コマンドヘルプを表示します |
| `!ping` | Botの応答確認を行います |
